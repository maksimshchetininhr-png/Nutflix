Nutflix TV 0.1.0

An Android TV / Google TV client for Philips televisions, with a TV home, the documented FramexTV embed interface, remote playback controls, and a local title library with resume.

Downloads
- Nutflix-TV.apk: sideloadable development APK (package tv.nutflix, Android 6.0+).
- Nutflix-TV.zip: APK, installation guide, and SHA-256 checksum.
- Nutflix-TV.apk.sha256: APK checksum.

Validation
- Android build and APK signature verification passed.
- Six core checks and five browser tests passed.
- Live FramexTV home/embed URLs and published protocol checked over verified HTTPS.
- Actual streaming on a physical TV remains unverified.

Install using the included guide. This build uses a development signing key and has not been submitted to the Play Store.
